# 功能

按「编辑器内核 / 工具箱 / 壳层」三块列 NoteText 做什么、不做什么。

## 编辑器内核

| 功能 | 说明 |
|---|---|
| 多标签 | 同一文件只有一个标签；支持中键关闭、右键菜单（关闭其他/关闭已保存） |
| 分屏 | `Ctrl+\`，左右两个视图同步同一文档，比例可拖 |
| 语法高亮 | 30 种语言，按扩展名自动识别 |
| 代码折叠 | 行号槽的折叠箭头 |
| 括号匹配与配对着色 | 嵌套层级一眼看出 |
| 列块编辑 | 按住 `Alt` 拖选 |
| 选中即高亮 | 选一个词，全文相同词都淡底标出 |
| 5 色标记 | 右键「标记选中的词」，与书签分开：书签是行级，标记是词级 |
| 书签 | `F2` 切换，侧栏面板列出并显示该行内容；右键可复制/剪切/删除书签行、删除非书签行 |
| 右键菜单 | 撤销重做、剪切复制粘贴、行操作、大小写、排序、去重、去行尾空白、Tab 空格互转、书签行操作、标记 |
| 转到行 | `Ctrl+G`，输入行号 |
| 行注释 | `Ctrl+/`，按语言给注释符 |
| 缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0`，50%–200% |
| 只读模式 | 文件属性为只读时提示另存为，不静默失败 |

## 编码与行尾

- 打开时探测编码（BOM 优先，再按字节特征判），置信度低时在状态栏标 `?`；
- 状态栏可直接切换编码重新载入；
- 行尾独立切换（CRLF / LF / CR），保存时按当前值写回；
- 保存遵循「打开时的编码 + 行尾 + BOM」，不偷偷转换。

## 工具箱

| 工具 | 细节 |
|---|---|
| JSON | 格式化（缩进 0–8 可调）、压缩、键排序、校验（带行列号）、JSONPath（`$..key` / `[n]` / `[*]`）、转 5 种语言结构体 |
| 文本对比 | LCS 行级对齐 + 行内字符级高亮；可忽略空白 / 大小写；可交换左右 |
| 目录对比 | 递归比较两个文件夹，标出仅左/仅右/有差异/相同，差异排在前面 |
| 哈希 | MD5 / SHA-1 / SHA-256，大小写两种输出，可算文件 |
| 正则 | 实时匹配 + 捕获组表格；`i` `m` `s` `x` 四个开关 |
| 编码转换 | 24 种编码互转，可选写 BOM |
| 行编辑 | 11 种：移除空行、去行尾空白、大小写三态、反转、合并空行、反转行序、去重、升降序 |
| 格式转换 | JSON / YAML / TOML / XML 互转，可从当前标签载入，结果可互换继续转 |
| 取色器 | 屏幕取色（不支持时退化为手动输入），HEX / RGB / HSL 分别可复制 |
| 日志查看器 | 直接读应用日志，按级别着色，可按错误/警告过滤 |

## 视图器

按扩展名自动分流：Markdown 走三态编辑器、图片走图片查看器、日志走日志视图
（ERROR/WARN 行着色）、二进制走十六进制视图。

## 文件树

- 懒展开：只有展开过的目录才读，子项缓存按目录；
- 右键全套：新建文件 / 新建文件夹（行内输入）、重命名、删除（删前确认）、
  剪切 / 复制 / 粘贴、创建副本、复制路径、在资源管理器显示；
- 树内拖拽：把一个节点拖进目标文件夹即移动，目标行高亮，
  拖进自己的子文件夹会被拒绝（目录树会成环）；
- 外部变更自动刷新：别的程序改了文件，树跟着更新。

## Markdown

`.md` 默认进三态视图：编辑 / 分屏 / 预览。

- 代码块语法高亮（highlight.js）；
- ```` ```mermaid ```` 块渲染成图，深浅主题跟随，渲染失败退回源码；
- `$公式$` 用 KaTeX 渲染；
- 一键导出 HTML（样式内联，可在任意浏览器打开）；
- 编辑态就是普通编辑器：撤销历史、快捷键、右键菜单全都在。

## 壳层

| 功能 | 说明 |
|---|---|
| 单实例 | 双击第二个文件会转交给已开着的窗口 |
| 托盘 | 可关闭到托盘常驻；托盘可唤出窗口、新建文档、退出 |
| 文件关联 | 安装器可选注册为常见文本类型的打开方式（不抢占默认） |
| 会话恢复 | 启动恢复上次的标签、光标、窗口大小；新建未保存的标签内容也恢复 |
| 自动保存 | 可开，间隔可设 |
| 文件监控 | 外部改文件会提示；日志文件可 `tail -f` |
| 备份 | 导出/导入书签、片段、宏、草稿、最近文件 |

## 明确不做

- 不做多窗口（单窗口 + 多标签覆盖 99% 场景）；
- 不做插件系统（参考项目做过，实际使用率极低，维护成本高）；
- 不做云同步 / 账号（数据本机，导出备份手动搬）；
- 不做自动更新（安装包就是全部）。
