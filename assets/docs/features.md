# 功能

按「编辑器内核 / 工具箱 / 壳层」三块列 NoteText 做什么、不做什么。

## 编辑器内核

| 功能 | 说明 |
|---|---|
| 多标签 | 同一文件只有一个标签；支持中键关闭、右键菜单（关闭其他/关闭已保存） |
| 分屏 | `Ctrl+\`，左右两个视图同步同一文档，比例可拖 |
| 语法高亮 | 31 种语言，按扩展名自动识别 |
| 代码折叠 | 行号槽的折叠箭头 |
| 括号匹配与配对着色 | 嵌套层级一眼看出 |
| 列块编辑 | 按住 `Alt` 拖选 |
| 选中即高亮 | 选一个词，全文相同词都淡底标出 |
| 5 色标记 | 右键「标记选中的词」，与书签分开：书签是行级，标记是词级 |
| 书签 | `F2` 切换，侧栏面板列出并显示该行内容；右键可复制/剪切/删除书签行、删除非书签行 |
| 右键菜单 | 撤销重做、剪切复制粘贴、行操作、大小写、排序、去重、去行尾空白、Tab 空格互转、书签行操作、标记 |
| 转到行 | `Ctrl+G`，输入行号 |
| 行注释 | `Ctrl+/`，按语言给注释符 |
| 缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0`，50%–200% |
| 只读模式 | 文件属性为只读时提示另存为，不静默失败 |

## 编码与行尾

- 打开时探测编码（BOM 优先，再按字节特征判），置信度低时在状态栏标 `?`；
- 状态栏可直接切换编码重新载入；
- 行尾独立切换（CRLF / LF / CR），保存时按当前值写回；
- 保存遵循「打开时的编码 + 行尾 + BOM」，不偷偷转换。

## 工具箱

| 工具 | 细节 |
|---|---|
| JSON | 打开即自动执行：格式化（缩进 0–8 可调）、压缩、键排序、校验（带行列号）、JSONPath（`$..key` / `[n]` / `[*]`）、转 5 种语言结构体；「应用」写回选中的那段 |
| 文本对比 | LCS 行级对齐 + 行内字符级高亮；可忽略空白 / 大小写；可交换左右 |
| 目录对比 | 递归比较两个文件夹，标出仅左/仅右/有差异/相同，差异排在前面 |
| 哈希 | MD5 / SHA-1 / SHA-256，大小写两种输出，可算文件 |
| 正则 | 实时匹配 + 捕获组表格；`i` `m` `s` `x` 四个开关 |
| 编码转换 | 12 种编码互转（GB18030 / Big5 / Shift_JIS / EUC 完整码表），可选写 BOM |
| 行编辑 | 11 种：移除空行、去行尾空白、大小写三态、反转、合并空行、反转行序、去重、升降序 |
| 格式转换 | JSON / YAML / TOML / XML 互转；带选中文本打开即自动转换，「应用」写回选区，结果可互换继续转 |
| 取色器 | 屏幕取色（不支持时退化为手动输入），HEX / RGB / HSL 分别可复制 |
| 日志查看器 | 直接读应用日志，按级别着色，可按错误/警告过滤 |
| 压缩 / 解压 | 可写 16 种：7z / zip / tar 全家族（tgz / txz / tbz2 / tzst / tlz4 / tbr）/ cab / gz / bz2 / zst / xz / lz4 / br；只读 4 种（6 个扩展名）：rar / lzh（含 lha）/ cpio / ar（含 deb）。创建（密码 / 固实 / 分卷 / 排除规则 / 拖入源文件）、打开浏览（条目表 / 预览 / 追加 / 删除 / 格式转换 / 单条目直接编辑）、解压（覆盖 / 跳过 / 保留两者 / 批量多包）、完整性测试；浮窗内实时进度，可暂停 / 取消。中文系统上用资源管理器或 WinRAR 压出来的包，里面的中文文件名不会乱码 |
| 文件分卷 | 任意文件按大小切卷；选中 `.001` 一键扫齐同目录全部分卷并合并还原 |

## 视图器

按扩展名自动分流：Markdown 走三态编辑器、图片走图片查看器、日志走日志视图
（ERROR/WARN 行着色）、CSV / TSV / JSONL 走可编辑表格（自动识别分隔符与编码）、
XLSX / XLSM 走可编辑单元格网格（值与公式可改，样式与图表保留）、
HTML 走沙箱静态预览、二进制走十六进制视图。
Word / PDF / PPT 不做内置渲染，给「用系统程序打开」的出路。

**老 .xls 与 .ods**：可以看、可以另存为 xlsx，但不能原地改单元格
（它们的二进制结构与 OOXML 不同，写回会把样式弄丢）。
顶部的「另存为 xlsx」转一份就能进网格编辑。

表格链路都带**表内查找 / 替换**：输入关键词回车即高亮全部命中，
填上替换内容再点「全部替换」。

## 大表格

CSV / TSV / JSONL / 顶层 JSON 数组走同一套引擎，**不整篇读进内存**：

- 打开即建索引（记录边界对齐的稀疏索引），1000 万行约 1 秒；
- 滚动条按需取数，拖到哪里加载到哪里；1000 万行也能一路滚到底；
- `Ctrl+G` 跳行，输入行号直接定位；
- 改单元格、改值立即生效，格子标黄表示未保存；
- `Ctrl+S` 保存：未改动的行**原样搬运**，只重写你动过的那几行。

表格里以鼠标与键盘操作：

| 操作 | 怎么做 |
|---|---|
| 改一个格 | 点一下进入输入，`Enter` 提交；`Tab` 提交并右移；`Esc` 取消 |
| 在格之间移动 | 方向键；`Enter` / `F2` 进入编辑 |
| 调整列宽 | 拖列右边界；双击边界按内容自适应 |
| 复制 | 右键「复制单元格 / 复制整行」——整行粘进 Excel 直接分列 |
| 加行 / 删行 | 工具栏按钮，或右键菜单 |

JSONL（每行一个 JSON 对象）与顶层 JSON 数组（元素可以跨行）都按表格打开，
不用切进文本视图。

## 大文件

- 超过 64MB 弹窗选「普通打开」或「分块打开」；512MB 以上自动分块，上限 64GB；
- 分块视图一次只解码 1MB，支持按块导航与按行跳转；默认只读，点「编辑本块」才解锁；
- 保存只替换当前块的字节，写回前比对磁盘内容；截断的标签一律只读，避免保存时删掉后半段。

> 表格文件不受这个分档约束：CSV / TSV / JSONL 无论多大都走大表格引擎。

## 文件树

- 懒展开：只有展开过的目录才读，子项缓存按目录；
- 右键全套：新建文件 / 新建文件夹（行内输入）、重命名、删除（删前确认）、
  剪切 / 复制 / 粘贴、创建副本、复制路径、在资源管理器显示；
- 压缩右键：普通文件 / 文件夹一键「添加到压缩包」；压缩包文件右键直接
  打开浏览、解压到旁边、测试完整性；`.001` 分卷右键合并；
- 树内拖拽：把一个节点拖进目标文件夹即移动，目标行高亮，
  拖进自己的子文件夹会被拒绝（目录树会成环）；
- 外部拖入：把文件 / 文件夹从资源管理器拖进窗口即打开
  （文件开标签、文件夹设为工作区）；
- 外部变更自动刷新：别的程序改了文件，树跟着更新。

## Markdown

`.md` 默认进三态视图：编辑 / 分屏 / 预览。

- 代码块语法高亮（highlight.js）；
- ```` ```mermaid ```` 块渲染成图，深浅主题跟随，渲染失败退回源码；
- `$公式$` 用 KaTeX 渲染；
- 一键导出 HTML（样式内联，可在任意浏览器打开）；
- 编辑态就是普通编辑器：撤销历史、快捷键、右键菜单全都在。

## 壳层

| 功能 | 说明 |
|---|---|
| 单实例 | 双击第二个文件会转交给已开着的窗口 |
| 托盘 | 可关闭到托盘常驻；托盘可唤出窗口、新建文档、退出 |
| 文件关联 | 安装器可选注册为常见文本类型的打开方式（不抢占默认） |
| 会话恢复 | 启动恢复上次的标签、光标、窗口大小；新建未保存的标签内容也恢复 |
| 崩溃恢复 | 脏标签每 30 秒静默快照进草稿库；异常退出后下次启动提示从草稿箱恢复，源文件不会被自动覆盖 |
| 自动保存 | 可开，间隔可设 |
| 文件监控 | 外部改文件会提示；日志文件可实时跟踪新增内容 |
| 备份 | 导出/导入书签、片段、宏、草稿、最近文件 |

## 明确不做

- 不做多窗口（单窗口 + 多标签覆盖 99% 场景）；
- 不做插件系统（实际使用率极低，维护成本高）；
- 不做云同步 / 账号（数据本机，导出备份手动搬）；
- 不做自动更新（安装包就是全部）。
