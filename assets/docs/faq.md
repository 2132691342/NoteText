# 常见问题

## 打开中文文件是乱码

按状态栏上的编码按钮，手动选 `GB18030`（兼容 GBK/GB2312）再载入。
探测在无 BOM 的短文件上判不准——那种情况状态栏的编码名后面会带 `?`，
就是在提醒你「不确定，自己确认一下」。

## 保存后整个文件行尾变了

不会。NoteText 保存时按「打开时探测到的行尾」写回：CRLF 文件存回去还是 CRLF。
只有你在状态栏上显式切换行尾才会改。

## 打开大文件卡住了

- 32MB 以下：直接打开，正常编辑。
- 32MB ~ 512MB：弹窗让你选「普通打开（整篇可编辑）」或「分块打开（秒开）」。
- 512MB 以上：自动分块，最高 64GB。

分块模式下按块浏览，需要改内容时点「编辑本块」——只有当前这一块会被解锁，
保存时也只替换这部分的字节，其余内容一个不动。保存失败（比如这块被别的
程序先改了）会提示并重新加载，不会拿旧内容盖掉别人的新内容。

如果你只是要「盯着日志看」，用侧栏的「监控」面板更划算：
它只读增量，不会把整个文件读进内存。

## 关掉窗口后进程还在

这是「关闭到托盘」生效了。托盘图标（右下角通知区）右键 → 退出。
不想常驻：设置 → 通用 → 关掉「关闭时最小化到托盘」。

## 标签关了，没保存的内容没了

新建未保存的标签在关闭时会存一份草稿快照（上限 2MB），
下次启动会恢复。**已命名文件的修改不会自动存**——那是你的文件，
不替你做主。需要自动保存：设置 → 编辑器 → 自动保存。

## 快捷键改了没反应

三种可能：

1. 新键位和别的命令冲突了——设置里会直接提示冲突的是哪一个；
2. 焦点在输入框里——那时按键归输入框，除了 `Esc` 都不触发编辑器命令；
3. 改完没等防抖回写（400ms）就关了设置页——再打开看一下是否还在。

## 数据存在哪，卸载会丢吗

```
%APPDATA%\NoteText\
├── notetext.db    书签 / 片段 / 宏 / 草稿 / 最近文件 / 界面设置
├── logs\          日志
└── backup\        导出的备份
```

卸载**不会**删这些。要清空：设置 → 关于 → 打开数据目录，手动删。

## 想换电脑

设置 → 关于 → 导出备份，到新机器上导入。
备份含书签、片段、宏、草稿、最近文件；界面偏好不随备份走（那是本机的）。

## 出问题了怎么反馈

设置 → 关于 → 打开日志目录，把 `app.log` 一起带上。
日志开头会打印数据目录与版本号，那是定位问题的第一手信息。
