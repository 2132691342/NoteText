# 快速上手

NoteText 是一款面向开发者与重度文本处理用户的轻量级 Windows 桌面编辑器。
这篇带你走完最常见的几件事。

## 打开文件

| 方式 | 操作 |
|---|---|
| 单个文件 | `Ctrl+O`，或把文件拖进窗口 |
| 整个文件夹 | `Ctrl+K`，侧栏会出现文件树 |
| 双击关联文件 | 装的是安装包、且勾选了文件关联时，双击 `.txt` / `.md` / `.log` 等文件会用 NoteText 打开 |
| 命令行 | `NoteText.exe 路径\文件.txt` |

已经打开的标签会被聚焦，不会开第二个——同一个文件只有一个标签。

## 保存

- `Ctrl+S` 保存当前标签；
- `Ctrl+Shift+S` 另存为；
- 标签栏上的圆点表示状态：**实心 = 有未保存修改**，空心 = 已保存。

保存时会按「打开时探测到的编码 + 行尾」写回，不会悄悄把 GBK 文件转成 UTF-8。
想换编码或行尾，点状态栏上的编码 / 行尾按钮。

## 查找与替换

| 场景 | 快捷键 |
|---|---|
| 本文件查找 / 替换 | `Ctrl+F` / `Ctrl+H` |
| 整个文件夹里搜 | `Ctrl+Shift+F` |
| 跳到某一行 | `Ctrl+G` |

查找框打开时默认带上你选中的文本。目录查找支持 `*.ts` 这样的文件名匹配，
超大文件（> 8MB）会自动跳过。

## 工具箱

工具栏右侧的 `{}` 按钮，或者「工具」菜单：

| 工具 | 用途 |
|---|---|
| JSON | 格式化 / 压缩 / 校验 / JSONPath 查询 / 转结构体 |
| 对比 | 两段文本的行级 + 行内差异 |
| 哈希 | MD5 / SHA-1 / SHA-256，可算文件 |
| 正则 | 实时匹配测试 + 捕获组 |
| 编码 | 整体转码、行尾转换 |
| 行编辑 | 移除空行、去重、排序、大小写等 11 种 |

每个工具打开时都会带上编辑器里选中的内容，不用先手动复制。

## 侧栏

左侧五个面板：文件树、书签、代码片段、函数列表、文件监控。

- **书签**：编辑器里按 `F2` 给当前行加/去书签；
- **片段**：设置里添加，双击插入到光标处；
- **函数**：从当前文件里提取符号，点击跳转；
- **监控**：实时跟踪当前文件的新增内容，适合看日志。

## 关闭与退出

点 X 时：

1. 先自动保存会话（标签、光标、窗口大小），下次启动原样恢复；
2. 有未保存修改时会问你要不要保存；
3. 「关闭到托盘」开着的话，收进托盘而不是退出——托盘图标右键可以真正退出。

## 数据在哪

```
%APPDATA%\NoteText\
├── notetext.db     书签 / 片段 / 宏 / 草稿 / 最近文件 / 界面设置
├── logs\           app.log（全量）与 warn.log（告警）
└── backup\         导出的备份
```

卸载不会删这些；要清空请到「设置 → 关于 → 数据目录」手动删。
