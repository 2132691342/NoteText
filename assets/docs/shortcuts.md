# 快捷键

NoteText 的快捷键可以在「设置 → 快捷键」里改。下面是默认键位。

## 文件

| 快捷键 | 功能 |
|---|---|
| `Ctrl+N` | 新建标签 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+K` | 打开文件夹 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+W` | 关闭标签 |

## 编辑

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切 / 复制 / 粘贴 |
| `Ctrl+A` | 全选 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |
| `F3` / `Shift+F3` | 查找下一个 / 上一个 |
| `Ctrl+Shift+F` | 在文件夹中查找 |
| `Ctrl+G` | 转到行 |
| `Ctrl+D` | 复制当前行 |
| `Ctrl+Shift+K` | 删除当前行 |
| `Alt+↑` / `Alt+↓` | 上/下移动当前行 |
| `Ctrl+/` | 切换行注释 |
| `Ctrl+Shift+U` / `Ctrl+Shift+G` | 转为大写 / 小写 |

## 视图

| 快捷键 | 功能 |
|---|---|
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小 |
| `Ctrl+0` | 重置缩放 |
| `Ctrl+B` | 显示/隐藏侧栏 |
| `Ctrl+\` | 分屏 |
| `F11` | 全屏 |
| `Ctrl+P` | 打印 |

## 工具

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+J` | 格式化 JSON（选中即转选中，没选中转全文） |
| `Ctrl+Alt+J` | 压缩 JSON 成单行 |
| `Ctrl+Alt+E` / `Ctrl+Alt+U` | 加转义 / 去转义 |
| `Ctrl+Shift+D` | 文本对比 |
| `Ctrl+Shift+H` | 哈希 |
| `Ctrl+Shift+R` | 正则测试 |
| `Ctrl+Shift+E` | 编码转换 |
| `Ctrl+Shift+L` | 行编辑 |
| `Ctrl+Shift+C` | 格式转换（JSON/YAML/TOML/XML） |
| `Ctrl+Shift+V` | 剪贴板历史 |
| `F2` / `Shift+F2` | 切换书签 / 下一个书签 |
| `F1` | 用户手册 |

> 选中文字后，编辑器上方会浮出操作条：格式化 JSON、压缩 JSON、转 YAML、
> 大小写、查找，点一下原地生效；右键菜单的前排也是这些一步操作。

## 自定义

「设置 → 快捷键」里点击某个键位框，然后按新的组合键即可。
`Esc` 取消录制。新键位跟已有命令冲突时会直接提示冲突的那一个，不会静默覆盖。
